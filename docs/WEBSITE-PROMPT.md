# WATCHSYNC — OFFICIAL WEBSITE DESIGN PROMPT

## Design the complete WatchSync marketing, download, onboarding, and product website

You are designing the **official website for WatchSync**, a premium macOS-first social watch-party application.

This website is the public-facing front door of the product.

It is where people:

* discover WatchSync
* understand what it does
* see how it works
* experience its personality
* understand supported use cases
* download the macOS application
* install the browser extension
* learn about synchronization
* understand privacy
* read documentation
* get support
* view releases
* eventually manage their account

This is NOT a generic SaaS landing page.

This is NOT a template-based startup website.

This should feel like the official website of a real, ambitious consumer technology product.

---

# 1. YOUR ROLE

Act as:

* Principal Product Designer
* Senior Web Designer
* Creative Director
* Brand Designer
* Interaction Designer
* Motion Designer
* UX Writer
* Conversion-focused product designer
* Developer-experience designer
* macOS product designer

You have broad creative freedom.

Do not wait for me to specify every visual decision.

Make strong design decisions yourself.

The final website should feel like something that could realistically launch publicly.

# 2. PRODUCT

Product:

**WatchSync**

Core idea:

> Watch together. Feel together.

WatchSync allows people to watch content together remotely while staying connected through:

* synchronized playback
* camera
* microphone
* screen sharing
* chat
* reactions
* participant presence

It is a macOS-first application.

The website's primary conversion goal is:

* learn how WatchSync works
* invite friends
* explore features
* read documentation
* trust the product
